# 🛍️ Lumé – E-Commerce Website

### Small Things for Slow Days

## 📌 Project Overview

Lumé is a modern and responsive e-commerce website designed to provide a simple, elegant, and user-friendly online shopping experience.

The website offers a curated collection of lifestyle products, including candles, ceramics, skincare products, stationery, and textiles.

It features an attractive interface, product categories, interactive shopping cart, discount coupon functionality, special offers, and customer reviews.

The project focuses on creating a smooth shopping experience with a beautiful design and easy navigation.

## ✨ Features

### 1. Home Page
- Attractive landing page with a modern design.
- Brand introduction and promotional banner.
- Featured products section.
- Easy navigation between website sections.
- Shop New Arrivals and special offer buttons.

### 2. Product Categories
The website includes five shopping categories:

- 🕯️ Candles
- 🏺 Ceramics
- 🧴 Skincare
- 📓 Stationery
- 🛋️ Textiles

Users can select a category to view its available products.

### 3. Product Listing
- Displays product names and prices.
- Shows product ratings.
- Highlights new arrivals and bestselling products.
- Displays original and discounted prices.
- Provides Add to Cart functionality.
- Allows users to filter products by category.

### 4. Shopping Cart
- Add products to the shopping cart.
- Increase or decrease product quantities.
- Remove products by reducing their quantity to zero.
- Automatically calculates the subtotal.
- Displays the total number of items.
- Shows the final payable amount.
- Provides a slide-out cart panel.

### 5. Discount Coupon
- Supports promotional coupon codes.
- Apply the coupon code `LUME10`.
- Provides a 10% discount on eligible cart totals.
- Displays the discount amount automatically.
- Shows an invalid message for incorrect coupon codes.

### 6. Special Offers
- Features the Slow Sunday product bundle.
- Allows customers to add multiple products to their cart through one button.
- Displays promotional discounts.
- Provides a first-order discount coupon.

### 7. Customer Reviews
- Displays customer feedback.
- Shows customer ratings and star reviews.
- Includes customer names and locations.
- Helps visitors understand the shopping experience.

### 8. Newsletter Subscription
- Provides an email subscription form.
- Accepts valid email addresses.
- Displays a subscription confirmation message.
- Allows users to receive updates about new products and offers.

### 9. Additional Features
- Responsive design for desktop, tablet, and mobile devices.
- Elegant typography using Google Fonts.
- Light and dark theme support based on system preferences.
- Smooth scrolling and interactive hover effects.
- Accessible buttons and navigation.
- Modern product illustrations using SVG.
- Free shipping progress indicator.
